# c2c-006 · 决策后悔模拟器

Vue 3 + TypeScript + Vite 纯前端决策反思工具。支持录入 2–4 个方案、设置稳定/成长/自由/金钱权重、生成 1/5/10 年后悔指数与预演卡，并以 SVG 曲线比较“最不后悔”方向。

## 必须满足条件（硬门槛）

除加权评分外，可启用**不能被其他优点抵消**的必须条件：可逆性下限/上限、任一价值维度影响不低于/不高于指定值，并可为每条条件设置边界容忍带。

- 条件判断为三值：**满足 / 不满足 / 尚无法判断**。数据缺失（影响值可标为“未评估”）或实际值落在容忍带内时记为“尚无法判断”，方案保留为条件候选，不直接排除。
- 方案分三档：**具备资格 / 条件候选 / 不具备资格**。推荐只在具备资格的方案中按原评分产生；未获资格的方案分数与原因仍可查看，但不会因总分好看被推荐。
- 全部明确不满足时不选勉强胜者，返回每个方案的**待解决条件**；条件自相矛盾（同指标下限高于上限）或越界时暂停资格判断并报告冲突，分数仍可见。
- 条件随案例保存、结果页保留“本次计算依据”；任何条件修改后结果标记过期、重新推演才重算；一键关闭门槛即回到纯评分结果。

设计细节见 `docs/superpowers/specs/2026-10-07-must-meet-conditions-design.md`。

## 架构

- `src/core`：领域模型、输入校验、权重归一化、后悔评分、必须条件判断、预演与安全提示
- `src/ports`：案例仓储和打印端口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、分步组件和原生 CSS

## 运行与测试

```bash
npm install
npm run dev
npm test
npm run build
docker compose up --build
```

Docker 部署访问 `http://localhost:8106`。案例仅保存在当前浏览器。

指数是透明、确定性的本地规则：分别计算 1、5、10 年价值偏差和可逆性成本，再按 30% / 40% / 30% 合成总分。它不预测真实未来，也不替代医疗、法律或投资专业意见。
